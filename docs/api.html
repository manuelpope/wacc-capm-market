API

Six routes. The interactive documentation is at /docs while the server is running.

MethodRouteWhat it does
GET /api/tickers The curated universe: 69 tickers, grouped by sector
GET /api/analysis/{ticker} The full analysis
GET /api/analysis/{ticker}/sensitivity The WACC x g grid
POST /api/analysis/{ticker}/overrides Saves manual inputs and recomputes
DELETE /api/analysis/{ticker}/overrides Drops the overrides and goes back to automatic
GET /api/health The database path, the cache TTL and the analyst configuration

Overrides

POST /api/analysis/{ticker}/overrides accepts any subset of these: 

{
  "beta": 1.2,
  "risk_free_rate": 0.045,
  "equity_risk_premium": 0.055,
  "pretax_cost_of_debt": 0.055,
  "tax_rate": 0.25,
  "debt_weight": 0.15,
  "growth_rate": 0.03,
  "base_fcf": 1.2e10,
  "projection_years": 5
}
Every override has to be a finite number

Python's JSON parser accepts NaN and Infinity as literals, so a request can carry them. They are refused with a 422: a single one of them would turn every number of the answer into a NaN while the response still said 200. The error body is itself valid JSON, which is why the offending value comes back as the string "nan".

The answer

The response of /api/analysis/{ticker} is a fixed shape, so a client never has to guess: 

{
  "ticker": "AAPL",
  "name": "Apple Inc.",
  "sector": "Technology",
  "currency": "USD",
  "price": 351.475,
  "cache": {
    "status": "computed",
    "snapshot_at": "2026-11-24T13:40:12+00:00",
    "computed_at": "2026-11-24T13:40:14+00:00",
    "ttl_hours": 24.0
  },
  "inputs":        { "risk_free_rate": 0.0451, "beta": 1.12, ... },
  "field_sources": { "beta": "yahoo", "roe": "llm", ... },
  "overrides":     null,
  "wacc":    { "cost_of_equity": 0.1011, "wacc": 0.1027, ... },
  "growth":  { "raw_growth": 1.061, "growth": 0.05, "capped": true, "reason": "..." },
  "valuation": { "base_fcf": 114540000000, "value_per_share": 155.33, ... },
  "news":    [ { "title": "...", "publisher": "...", "published_at": "..." } ],
  "warnings": [ "..." ]
}

The things worth knowing about it:

  • cache.status is one of computed, fresh, stale or refreshed.
  • field_sources says where every field came from: yahoo, a named fallback, or llm.
  • growth.reason explains every cap that fired.
  • valuation is null when it could not be computed, and the reason is in the warnings.
  • warnings is the honest part. Read it before the numbers.

Status codes

CodeWhen
