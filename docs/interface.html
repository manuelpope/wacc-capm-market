The interface

One page, no build step. Pick a ticker, read the result, override what you disagree with.

The units

Every monetary value is shown with the currency of the ticker — never as a raw number:

  • $136.06B for a hundred and thirty-six billion
  • $3.36T for three point three six trillion
  • $179.43 for a price

The currency comes from the quote profile and is carried through the whole response, so a client can format the numbers the same way the interface does.

The overrides

Every automatic value in the inputs table has an empty box next to it. Type a number, press Save overrides & recompute, and the answer is recomputed with your number in place of the automatic one. The overrides are stored per ticker, so they survive a restart.

Reset to automatic drops them and goes back to what Yahoo says. The percentages are typed as percentages (4.5 means 4.5%, not 0.045), and a value that cannot be read is named in the status line instead of being ignored.

Which values can be overridden

The beta, the risk-free rate, the equity risk premium, the pre-tax cost of debt, the tax rate, the debt weight, the growth rate, the base free cash flow and the projection horizon. The capital structure, the share count and the net debt come from the provider and are not editable — they are facts about the company, not assumptions.

The behaviour under pressure

  • Two requests can be in flight at once: the one that answers last is not the one that paints the screen. Every request carries an id, and the interface only draws the answer of the newest one.
  • The same rule applies to the overrides and to the grid, so a slow grid can never overwrite a fresh analysis.
  • The error message and the grid warning are rendered as text, never as HTML, so a hostile ticker cannot inject anything into the page.
